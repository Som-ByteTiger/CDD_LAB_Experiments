# Github Actions Demo

Name: Somsubhra Khan
Subject: CDD

## Aim
To automatically run a Python program using GitHub Actions.

## Program
hello.py prints: Hello Github Actions

## Workflow
The workflow is located at:
.github/workflows/github-actions-demo.yml

It checks out the repository, sets up Python 3.12, and runs hello.py
from the Github_actions_demo folder on pushes and pull requests.

## Verification
Open the repository's Actions tab and inspect the workflow run.
